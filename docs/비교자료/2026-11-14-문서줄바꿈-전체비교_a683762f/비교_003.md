+<a id="guide-intro"></a>

+## 프로젝트 소개
+
+**이 연구는 청소년에게 같은 게임을 일괄 추천하는 대신, 그 사람과 비슷한 과거 사례를 참고해 놀이치료 게임을 고르는 방법을 제안합니다.** 예를 들어 연령과 이전 게임 반응을 함께 살펴 후보를 고른다는 구상입니다. 예시는 처리 방식을 풀어 쓴 것이며 실제 참가자 사례를 뜻하지 않습니다. **공개된 결과물은 추천 설계 논문**입니다.
+
+<a id="guide-problem"></a>
+
+## 문제와 주요 기능
+
+나이와 게임 경험이 다른 청소년에게 모두 같은 후보를 제시하면 개인 차이를 반영하기 어렵다는 문제에서 출발합니다. 여기서 사례란 사람의 특성과 게임 이용 뒤 반응을 함께 적어 둔 기록을 뜻합니다. 원고는 이런 정보를 추천에 쓰자고 제안합니다.
+
+<a id="guide-flow"></a>
+
+## 입력·처리·출력
+
+입력은 새 사용자의 특성과 기존 게임 경험입니다. 먼저 비슷한 기록을 찾고, 그 기록과 게임 정보를 바탕으로 후보를 고릅니다. 마지막으로 실제 이용 뒤 반응을 관찰해 다음 추천에 반영하는 순서입니다. 그림 속 연결은 설계이며 실행 화면은 아닙니다.
+

+<a id="guide-intro"></a>

+## 프로젝트 소개
+
+**핵심 개념은 사례 기반 추론(CBR)입니다.** 새 상황을 처음부터 규칙으로 풀기보다 기존 사례와의 유사성을 이용합니다. 이 원고에서는 청소년의 특성·게임 경험·성과를 사례로 연결하고, 검색한 사례를 게임 추천과 후속 평가에 재사용하는 구조를 설명합니다.
+
+<a id="guide-problem"></a>
+
+## 문제와 주요 기능
+
+사례에는 연령·성별 같은 특성뿐 아니라 게임 종류와 이용 반응도 연결됩니다. 게임을 단순 목록으로 고르는 문제에서, 어떤 사용자에게 어떤 게임이 맞을지 과거 자료로 판단하는 문제로 바뀝니다. 기억력·집중력 향상은 이 설계가 지향하는 목표입니다.
+
+<a id="guide-flow"></a>
+
+## 입력·처리·출력
+
+사례 수집 → 유사성 평가 → 사례 검색 → 추천 적용 → 결과 평가로 이어집니다. 시스템 그림에는 MMSE 검사결과, 게임 후보 생성, CBR 추천 모델과 게임 메타데이터가 연결됩니다. 각 화살표가 어떤 정보를 넘기는지 구분하면 전체 흐름을 읽기 쉽습니다.
+
+<a id="guide-practice"></a>
+
+## 실험과 사용 흐름
+
+원고의 CBR 설명을 읽은 다음 시스템 구조도에서 사례 저장·검색·후보 추천·평가를 찾아봅니다. 이후 결론에서 제안한 활용 방향과 아직 필요한 실증을 구분합니다. 논문의 보관 폴더 연도와 학술대회 표기는 별개입니다.
