# 🕹️ 최종 원고 · 사례로 찾는 디지털 놀이치료

**청소년의 특성과 게임 반응을 사례로 보관하고, 비슷한 사례를 이용해 디지털 놀이치료 게임을 추천하는 설계 연구입니다.**

**기술 분류:** 추천 시스템 › 사례 기반 추론(CBR) › 청소년 디지털 놀이치료 설계

[목적](#purpose) · [기능](#features) · [입출력](#flow) · [구성](#files) · [준비](#setup) · [사용법](#usage) · [결과](#results) · [제약](#limits) · [변경](#changes)

</div>

<a name="purpose"></a>

## 🎯 이 단계에서 하는 일

이 원고의 중심은 사례 수집→유사 사례 검색→추천 적용→반응 평가의 연결입니다. 치료 대상의 특성, 게임 메타데이터와 과거 이용 경험을 추천 근거로 다루며, 실제 참여자 기록을 제공하는 데이터셋이나 실행 앱은 별도로 포함하지 않습니다.

<a name="features"></a>

## 🧩 주요 기능과 처리 방식

| 구성 | 실제 역할 |
| --- | --- |
| 사례 구성 | 나이·성별 등 사용자 특성과 게임 유형·반응·성과를 한 사례로 연결합니다. |
| 사례 검색 | 새로운 사용자의 특성에 맞는 과거 사례를 찾아 추천 근거로 사용합니다. |
| 게임 후보 구성 | 게임 메타데이터와 이전 반응을 바탕으로 개인에게 맞는 콘텐츠를 선택하는 흐름을 설명합니다. |
| 추천 후 평가 | 게임 이용 이후 반응과 인지 성과를 관찰하고 다음 추천에 반영하는 설계를 제시합니다. |

<a name="usage"></a>

## 📖 읽고 활용하는 순서

1. PDF의 서론에서 ADHD 청소년을 위한 추천의 필요성과 기존 게임 기반 접근을 읽습니다.
2. Ⅱ장의 CBR 설명에서 사례에 무엇을 저장하고 새로운 사용자와 어떻게 연결하는지 따라갑니다.
3. 시스템 구조 그림에서 사용자·게임 후보·사례 검색·평가의 관계를 확인합니다.
4. 결론에서 제안한 추천 방식의 활용 방향과 실제 효과 평가가 필요한 부분을 구분합니다.

<a name="results"></a>

## 📊 결과를 읽는 방법

원고에는 정량 성능 결과표, 참여자 수·대조군 비교·통계 검정으로 입증한 임상 효과가 제시되지 않습니다. 따라서 이 자료에서 읽을 결과는 추천 시스템의 설계와 처리 흐름입니다.

기억력·집중력 향상은 설계의 목표입니다. 실제 사용자 반응을 수집하고 추천 결과를 평가하려면 개인정보 보호와 연구 절차를 갖춘 별도의 실증이 필요합니다. 원고에 쓰인 목표를 이미 측정된 치료 효과로 바꾸어 해석하지 않습니다.

| 효과 수치를 인용할 때 | 이 원고는 설계 제안이며 치료 전후의 정량 실험 결과를 제공하지 않습니다. |
