# 📄 최종 원고

CBR 기반 디지털 놀이치료 추천의 설계 원고입니다.

[최종 원고 읽기](../../%EB%85%BC%EB%AC%B8/%EC%B5%9C%EC%A2%85_%EB%85%BC%EB%AC%B8.pdf) · [프로젝트 소개](../../README.md) · [연구 자료](../VERSIONS.md)

## 🔎 연구 범위

원고에는 정량 결과표와 임상 효과를 입증할 수 있는 참여자·통계 검정 결과가 제시되지 않습니다.

청소년 특성과 게임 반응의 유사 사례를 활용하는 CBR 추천 구조와 평가 절차를 최종 원고에 정리했습니다.


## 🧩 주요 내용

- 청소년 특성·게임 반응 사례를 검색·재사용하는 CBR 구성을 설명합니다.
- 개인화 추천을 통한 인지 능력 향상을 목표로 하며, 임상 효과 검증은 후속 과제입니다.

## 🔄 자료 구성

이 저장소는 최종 원고 한 편을 공개합니다. 연구 방법과 처리 흐름을 원고에 정리했습니다.
