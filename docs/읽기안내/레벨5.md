## 프로젝트 소개

**검토 대상은 CBR 기반 디지털 놀이치료 추천의 개념 설계입니다.** 학술대회 원고의 추천 흐름과 시스템 구성도는 공개 근거이지만, 검색 함수·유사도 정의·표본·평가 추정량이 완비된 실증 연구로 볼 근거는 없습니다. **설계 산출물과 임상 효과 추정은 구분**합니다.

| 항목 | 핵심 내용 |
| --- | --- |
| 기능 | 연구 질문의 타당성은 사례 표현, 유사성, 추천 정책, 효과 평가의 연결로 검토합니다.<br>어떤 변수를 비교하고 어떤 결과를 예측할지 명확하지 않으면 사례 검색의 적합도를 정량 평가하기 어렵습니다.<br>현 원고에는 이를 검증할 실측 표본이나 정량 결과표가 없습니다. |
| 입력·처리 | 추천 이후 관측을 사례 갱신에 사용하는 설계에서는 학습·평가 시점의 분리가 중요합니다.<br>공개 자료는 이 피드백 구조를 설명하지만 시간 분할, 대조군, 업데이트 정책을 검증할 데이터는 제공하지 않습니다.<br>제안된 인지 평가와 실제 임상 추정의 식별 조건을 혼동하지 않습니다. |
| 실행 | 재현성 검토는 원고의 주장 범위를 먼저 고정한 뒤 수행합니다.<br>설계의 존재는 PDF로 확인되지만 효능 재현에 필요한 표본·분할·추천 정책·통계 절차는 별도로 필요합니다.<br>이 부재를 재현 성공으로 처리할 수 없습니다. |

| 구현 | 공개 산출물은 실행 아티팩트가 아닌 설계 원고입니다.<br>모델 파라미터·데이터 계보·실험 추적 로그를 분석할 대상이 제공되지 않았습니다.<br>자료 구성과 개념 구조의 일관성을 검토하는 범위로 제한합니다. |

<a id="guide-problem"></a>

## 문제와 주요 기능

연구 질문의 타당성은 사례 표현, 유사성, 추천 정책, 효과 평가의 연결로 검토합니다. 어떤 변수를 비교하고 어떤 결과를 예측할지 명확하지 않으면 사례 검색의 적합도를 정량 평가하기 어렵습니다. 현 원고에는 이를 검증할 실측 표본이나 정량 결과표가 없습니다.

<a id="guide-flow"></a>

## 입력·처리·출력

추천 이후 관측을 사례 갱신에 사용하는 설계에서는 학습·평가 시점의 분리가 중요합니다. 공개 자료는 이 피드백 구조를 설명하지만 시간 분할, 대조군, 업데이트 정책을 검증할 데이터는 제공하지 않습니다. 제안된 인지 평가와 실제 임상 추정의 식별 조건을 혼동하지 않습니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

재현성 검토는 원고의 주장 범위를 먼저 고정한 뒤 수행합니다. 설계의 존재는 PDF로 확인되지만 효능 재현에 필요한 표본·분할·추천 정책·통계 절차는 별도로 필요합니다. 이 부재를 재현 성공으로 처리할 수 없습니다.

<a id="guide-results"></a>

## 관측 결과와 해석

임상 효과 추정에 필요한 표본 크기, 대조 조건, 평가 시점, 효과량과 불확실성이 없습니다. 따라서 정량 성능·치료 효과에 대한 비교 우위는 판단할 수 없습니다. 설계의 참신성과 효과성 증거의 수준을 별도 축으로 검토합니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

공개 산출물은 실행 아티팩트가 아닌 설계 원고입니다. 모델 파라미터·데이터 계보·실험 추적 로그를 분석할 대상이 제공되지 않았습니다. 자료 구성과 개념 구조의 일관성을 검토하는 범위로 제한합니다.

<a id="guide-paper"></a>

## 실제 논문과 원고

인용 시 학술대회명·인쇄쪽수·저자와 함께 연구 유형을 설계 제안으로 명시합니다. 논문의 존재와 임상 검증의 존재는 다른 사실입니다. 전체 원고의 서지·본문을 근거로 하며 제공되지 않은 평가를 보완해 적지 않습니다.

<a id="guide-limits"></a>

## 조건·실패·미검증 한계

주장의 상한은 추천 구조와 평가 절차의 제안입니다. 임상적 일반화, 하위집단 효과, 반복 추천의 장기 영향, 개인정보 위험에 대한 실증 근거는 제공되지 않았습니다. 이 한계를 포함해 연구의 기여를 평가합니다.

### LEVEL 5 · MMSE·개인 특성·게임 정보가 연결되는 방식

원고의 CBR 처리도와 사례항목·MMSE·게임 메타데이터의 역할을 설계 근거로 검토합니다.유사도 수식·가중치·실행 구현이 제시되지 않아 추천 재현성이나 유효성의 수치평가는 불가능합니다.입력 구조와 검증된 알고리즘을 구분해야 합니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-3-row-1"></a> 사례의 구성 | 나이·성별 등 특성,게임 유형·플레이 기록·반응과 인지 성과를 한 사례로 연결하는 제안입니다.실제 환자 기록이나 이용 로그를 제공하는 데이터베이스는 아닙니다. |
| <a id="layout18-table-3-row-2"></a> MMSE 검사 결과와 후보 생성 | 원고 2쪽 시스템 그림은 MMSE라는 검사 결과 정보와 개인 특성을 게임 후보 생성에 연결합니다.<br>검사 점수만으로 ADHD 진단이나 치료 결정을 내리는 구현을 제공하지 않습니다. |
| <a id="layout18-table-3-row-3"></a> 게임 메타데이터 | 메타데이터는 게임 종류와 같은 게임을 설명하는 부가정보입니다.과거 사례와 함께 CBR 추천 모델에 들어가 개인별 후보 선택의 근거가 되는 구조입니다. |
| <a id="layout18-table-3-row-4"></a> 사례 기반 추론 CBR | 과거의 비슷한 사례를 찾아 새 추천에 참고하는 접근입니다.원고 순서는 사례 수집→유사성 평가→사례 검색→추천 적용→결과 평가입니다. |


<a id="semantic-evaluation-level-5"></a>

### LEVEL 5 · 추천 후 평가와 아직 제시되지 않은 성과

임상 참여자·대조군 전후평가·통계검정·추천 성능·재현 코드의 미제시를 각각 유지합니다.구조적 타당성 검토는 가능하지만 치료 효과·임상 적용성·추천 정확도를 검증한 근거로 확대할 수 없습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-4-row-1"></a> 연구 목표 | 기억력·집중력 훈련 게임 중 개인에게 맞는 후보를 찾고 인지 능력 향상을 돕는 것이 목표입니다.목표를 이미 관측한 개선 성과로 바꾸지 않습니다. |
| <a id="layout18-table-4-row-2"></a> ADHD·대조군 사례 수집 제안 | 환자와 정상 대조군의 특성·게임 반응을 수집하는 절차를 제안합니다.실제 참여자 수·수집 표본·사례 데이터는 제공하지 않습니다. |
| <a id="layout18-table-4-row-3"></a> 추천 이후의 평가 | 이용 반응과 인지 성과를 관찰해 다음 추천에 반영하는 설계입니다.치료 전후 비교·대조군 실험·통계검정을 수행한 효과 검증은 후속 과제입니다. |
| <a id="layout18-table-4-row-4"></a> 구현·결과 부재 | 정량 성능표·구체 유사도 수식·학습 데이터·실행 가능한 추천 서비스는 원고에 없습니다.임의의 계산식이나 임상 수치를 새로 만들어 보완하지 않습니다. |


<a id="semantic-paper-level-5"></a>

### LEVEL 5 · 전체 원고를 확인하는 순서와 자료 범위

3쪽 전체 원고와 출처·도표 위치를 고정해 설계 주장만 인용합니다. 발표 연도/보관 연도 및 단일 최종 원고/설명 문서 구분을 유지하며, 코드 부재나 임상 미검증을 다른 저장소의 결과로 대신하지 않습니다.

## 구조도와 서지를 이 수준에서 해석하기

**프로토콜 검토의 범위:** 시스템 구성도는 MMSE 검사결과·개인 특성, 게임 메타데이터, 후보 생성, CBR 검색의 정보 연결을 제시합니다.

사례 수집→유사성 평가→사례 검색→추천 적용→결과 평가를 검토할 때 사례 표현·거리 정의·검색 정책·추천 정책·평가 추정량을 구분합니다.

원고가 제공하지 않은 수식과 데이터 분할·표본 조건은 미확정으로 남깁니다.

이 구조는 개인화의 설계 근거이며 임상 효과에 대한 식별·추정 절차가 완결됐다는 근거가 아닙니다. 참여자 수·대조군·전후 평가·통계 검정이 없어 효과량·불확실성·일반화를 판단할 수 없습니다. 구체적 실행 앱과 학습 데이터도 제공되지 않습니다.

서지 근거는 곽윤석·김도연·박정수·안진호, 2024 한국정보기술학회 추계 종합 학술 대회 논문집, 인쇄 쪽 수 1727 –1729의 3쪽 원고입니다.

학회 영문 명 Korean Institute of Information Technology와 제목 Digital Play Therapy Algorithm for ADHD Adolescent Patients를 원고에 맞춰 보존합니다.
