<a id="guide-intro"></a>

## 프로젝트 소개

이 연구는 청소년에게 같은 게임을 일괄 추천하는 대신, 그 사람과 비슷한 과거 사례를 참고해 놀이치료 게임을 고르는 방법을 제안합니다. 예를 들어 연령과 이전 게임 반응을 함께 살펴 후보를 고른다는 구상입니다.

예시는 처리 방식을 풀어 쓴 것이며 실제 참가자 사례를 뜻하지 않습니다.

**공개된 결과물은 추천 설계 논문**입니다.


<a id="guide-problem"></a>

## 문제와 주요 기능

| 대상·조건 | 동작과 의미 |
| --- | --- |
| 게임 후보·반응 | 나이와 게임 경험이 다른 청소년에게 모두 같은 후보를 제시하면 개인 차이를 반영하기 어렵다는 문제에서 출발합니다. |
| 사례 구성·활용 | 여기서 사례란 사람의 특성과 게임 이용 뒤 반응을 함께 적어 둔 기록을 뜻합니다. |
| 원고·판본 구분 | 원고는 이런 정보를 추천에 쓰자고 제안합니다. |

| --- | --- |

| 추천·순위 평가 | 마지막으로 실제 이용 뒤 반응을 관찰해 다음 추천에 반영하는 순서입니다. |
| 논문 구조도 | 그림 속 연결은 설계이며 실행 화면은 아닙니다. |

### LEVEL 1 · MMSE·개인 특성·게임 정보가 연결되는 방식

사람을 설명하는 정보와 게임을 설명하는 정보를 함께 보자는 설계입니다.

먼저 원고 2쪽 그림에서 MMSE 검사 정보, 게임 후보, 게임 메타데이터를 각각 찾고 추천 모델로 향하는 연결을 따라가 보세요.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-3-row-1"></a> 사례의 구성 | 나이·성별 등 특성,게임 유형·플레이 기록·반응과 인지 성과를 한 사례로 연결하는 제안입니다.실제 환자 기록이나 이용 로그를 제공하는 데이터베이스는 아닙니다. |

### LEVEL 1 · 추천 후 평가와 아직 제시되지 않은 성과

좋아지도록 돕겠다는 목표와 실제 좋아졌다는 결과는 다릅니다.**이 자료의 결과물은 추천 구조와 평가 절차의 제안**입니다.

게임 추천을 보았다는 사실만으로 치료 효과가 있다고 판단하지 않습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-4-row-1"></a> 연구 목표 | 기억력·집중력 훈련 게임 중 개인에게 맞는 후보를 찾고 인지 능력 향상을 돕는 것이 목표입니다.목표를 이미 관측한 개선 성과로 바꾸지 않습니다. |
| <a id="layout18-table-4-row-2"></a> ADHD·대조군 사례 수집 제안 | 환자와 정상 대조군의 특성·게임 반응을 수집하는 절차를 제안합니다.실제 참여자 수·수집 표본·사례 데이터는 제공하지 않습니다. |
| <a id="layout18-table-4-row-3"></a> 추천 이후의 평가 | 이용 반응과 인지 성과를 관찰해 다음 추천에 반영하는 설계입니다.치료 전후 비교·대조군 실험·통계검정을 수행한 효과 검증은 후속 과제입니다. |
| <a id="layout18-table-4-row-4"></a> 구현·결과 부재 | 정량 성능표·구체 유사도 수식·학습 데이터·실행 가능한 추천 서비스는 원고에 없습니다.임의의 계산식이나 임상 수치를 새로 만들어 보완하지 않습니다. |

## 구조도와 서지를 이 수준에서 해석하기

**구조도에 나온 이름을 풀어 읽기:** CBR은 기존 사례를 참고해 새 추천을 만드는 방식입니다.

MMSE 검사 결과는 구조도에서 사용자에 관한 검사 정보를 연결한 입력 항목입니다.

원고가 새 임상 시험으로 측정한 효과 수치가 아닙니다.

게임 메타데이터는 게임을 설명하는 정보이고, 게임 후보 생성은 이런 정보로 추천할 대상을 먼저 모으는 단계입니다.

사용자의 정보와 게임 정보를 연결한 뒤 CBR이 비슷한 사례를 찾도록 구성합니다.

**다섯 단계의 차이:** 사례 수집은 사람 특성과 게임 반응 기록을 모으는 일, 유사성 평가는 새 사용자와 기록을 어떤 기준으로 비교할지 보는 일입니다.

사례 검색은 비교 결과에 맞는 기록을 찾는 일이고, 추천 적용은 그 기록을 바탕으로 게임을 고르는 일입니다.

결과 평가는 이용 뒤 반응과 성과를 확인하는 절차입니다.

이 흐름이 제안됐다는 사실과 실제 참여자에게 실행해 효과를 얻었다는 사실은 다릅니다.

**논문 정보 읽기:** 저자는 곽윤석·김도연·박정수·안진호입니다. 2024 한국정보기술학회 추계 종합 학술 대회 논문집의 인쇄 쪽 수 1727 –1729에 실린 전체 3쪽 원고입니다.

학회 영문 이름은 Korean Institute of Information Technology이며 원고 제목은 Digital Play Therapy Algorithm for ADHD Adolescent Patients입니다.

폴더의 보관 연도로 논문의 연도를 바꾸지 않습니다.
