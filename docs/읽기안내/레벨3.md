<a id="guide-intro"></a>

## 프로젝트 소개

**이 저장소를 재현 자료로 사용할 때는 실행 실험과 원고의 설계 분석을 구분해야 합니다.** 제공물은 전체 학술대회 원고이며 학습 데이터나 실행 가능한 추천 앱은 없습니다. 따라서 먼저 사례 필드와 처리 단계의 대응을 문서에서 확인하는 것이 가능한 작업입니다.

<a id="guide-problem"></a>

## 문제와 주요 기능

원고를 읽으며 추천 입력 필드, 검색에 필요한 비교 항목, 추천 후 수집할 반응을 별도로 적어 보세요. 입력 항목이 있다고 해서 실제 수집 데이터가 있다는 뜻은 아닙니다. 공개 원고에 제안된 항목과 제공된 파일의 범위를 먼저 맞춥니다.

<a id="guide-flow"></a>

## 입력·처리·출력

입력·처리·출력 표에서 사용자 특성과 기존 사례가 검색 입력인지, 게임 이용 후 반응이 평가 입력인지 구분합니다. 추천 전 자료와 추천 뒤 관측을 한 시점의 입력처럼 섞지 않습니다. 실제 원고의 구조도를 따라 각 단계의 입출력을 확인하세요.

<a id="guide-practice"></a>

## 실험과 사용 흐름

실행 재현의 출발점은 제공 파일 확인입니다. PDF로 방법과 도표를 검토할 수 있지만 데이터셋이나 실행 코드가 없어 같은 추천 결과를 계산하는 재실행은 할 수 없습니다. 추가 구현을 구상한다면 원고에 없는 유사도와 데이터 조건을 기존 결과처럼 채우지 않습니다.

<a id="guide-results"></a>

## 관측 결과와 해석

결과를 인용할 때는 “사례 기반 개인화 추천 구조를 제안했다”는 범위로 기술합니다. 정확도나 치료 효과 수치를 찾아 채우지 않습니다. 참여자·대조군·전후 평가가 없어 설계의 임상적 우위를 수치로 재현할 수 없습니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

구현 핵심 파일을 찾는 경우 전체 원고가 방법의 근거 파일입니다. 실행 노트북·함수 정의·학습 설정은 제공되지 않습니다. 아래 차수 표의 자료 폴더와 상세 설명, 전체 구성을 통해 공개물의 범위를 확인하세요.

<a id="guide-paper"></a>

## 실제 논문과 원고

원문 PDF의 서론·CBR 설명·시스템 그림·결론을 대응해 읽으세요. 저자는 곽윤석·김도연·박정수·안진호입니다. 단일 최종 원고 안내이므로 확인되지 않은 과거 실험 차수나 비교 성능을 만들지 않습니다.

<a id="guide-limits"></a>

## 조건·실패·미검증 한계

추가 실험을 계획하려면 실제 사용자의 반응을 어떤 절차로 수집하고 어떤 기준으로 평가할지 별도로 정해야 합니다. 현재 공개물은 원자료를 제공하지 않습니다. 프로그램이 없다는 점과 임상 평가가 없다는 점을 각각 기록합니다.

#### LEVEL 3 · 원고가 보고한 결과와 한계

기억력·집중력 훈련 게임 중 개인에게 맞는 후보를 찾는 것이 연구의 출발점입니다. 원고는 ADHD 환자와 정상 대조군의 특성·게임 반응을 사례로 수집하는 절차를 제안하지만, 실제 수집 표본이나 사례 데이터는 제공하지 않습니다.

CBR 기반 개인화를 통해 인지 능력 향상을 돕는 것을 목표로 합니다. 이 연구는 추천 구조의 설계 단계이며, 임상 참여자·대조군의 전후 평가와 통계 검정을 통한 치료 효과 검증은 후속 과제입니다.

## 구조도와 서지를 이 수준에서 해석하기

**원고를 재구성할 때 확인할 항목:** 사용자 측 MMSE 검사결과와 개인 특성, 게임 메타데이터, 후보 생성, CBR 검색을 각각 입력·처리로 구분해 표에 대응합니다. 사례 수집→유사성 평가→사례 검색→추천 적용→결과 평가에서 각 출력이 다음 단계의 어떤 입력인지 확인합니다. 공개되지 않은 유사도 수식을 채워 넣은 구현은 이 원고 자체의 재실행이 아니라 추가 구현입니다.

추천 뒤 반응을 수집하는 계획과 실제 수집 데이터의 존재를 따로 확인하세요. 원고에는 정량 성능표나 참여자·대조군·통계 검정으로 입증한 임상 효과가 없습니다. 도표를 설명할 수 있는 것과 동일 추천·효과를 계산해 낼 수 있는 것은 다른 재현 범위입니다.

인용 기준은 저자 곽윤석·김도연·박정수·안진호, 2024 한국정보기술학회 추계 종합학술대회 논문집 1727–1729입니다. 영문학회명은 Korean Institute of Information Technology, 제목은 Digital Play Therapy Algorithm for ADHD Adolescent Patients입니다. PDF의 3쪽 구성과 보관 폴더를 구분해 자료를 확인합니다.
