# 📄 Digital Play Therapy Algorithm for ADHD Adolescent Patients

청소년의 특성과 게임 반응을 사례로 보관하고, 비슷한 사례를 이용해 디지털 놀이치료 게임을 추천하는 설계 연구입니다.

## 🧭 이 자료를 읽는 순서

1. PDF의 서론에서 ADHD 청소년을 위한 추천의 필요성과 기존 게임 기반 접근을 읽습니다.
2. Ⅱ장의 CBR 설명에서 사례에 무엇을 저장하고 새로운 사용자와 어떻게 연결하는지 따라갑니다.
3. 시스템 구조 그림에서 사용자·게임 후보·사례 검색·평가의 관계를 확인합니다.
4. 결론에서 제안한 추천 방식의 활용 방향과 실제 효과 평가가 필요한 부분을 구분합니다.

## 🔎 연결된 내용

| 구성 | 읽을 내용 |
| --- | --- |
| 사례 구성 | 나이·성별 등 사용자 특성과 게임 유형·반응·성과를 한 사례로 연결합니다. |
| 사례 검색 | 새로운 사용자의 특성에 맞는 과거 사례를 찾아 추천 근거로 사용합니다. |
| 게임 후보 구성 | 게임 메타데이터와 이전 반응을 바탕으로 개인에게 맞는 콘텐츠를 선택하는 흐름을 설명합니다. |
| 추천 후 평가 | 게임 이용 이후 반응과 인지 성과를 관찰하고 다음 추천에 반영하는 설계를 제시합니다. |
