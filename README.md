## 연구 요약

CBR 기반 디지털 놀이치료 추천의 설계 원고입니다.

원고에는 정량 결과표와 임상 효과를 입증할 수 있는 참여자·통계 검정 결과가 제시되지 않습니다.

- 청소년 특성·게임 반응 사례를 검색·재사용하는 CBR 구성을 설명합니다.
- 개인화 추천을 통한 인지 능력 향상을 목표로 하며, 임상 효과 검증은 후속 과제입니다.

## 연구 방법

저자: **곽윤석 · 김도연 · 박정수 · 안진호**

2024 한국정보기술학회 추계 종합학술대회 논문집, 인쇄쪽수 1727–1729. 학회 영문명은 **Korean Institute of Information Technology**입니다.

| 항목 | 원고에서 다루는 내용 |
| --- | --- |
| 사례 구성 | 나이·성별 등 특성, 게임 유형·플레이 기록, 인지 성과를 사례 항목으로 제안합니다. |
| 유사사례 검색 | 새 사용자의 특성을 기존 사례와 비교하여 추천 근거를 찾습니다. |

| 평가 설계 | 추천 이후 인지 능력 변화를 평가하는 절차를 제안합니다. |

원고 2쪽은 사례 수집 → 유사성 평가 → 사례 검색 → 추천 적용 → 결과 평가의 순서를 설명합니다. 시스템 그림에는 MMSE 검사 결과, 게임 후보 생성, CBR 추천 모델과 게임 메타데이터가 연결되어 있습니다.

<a name="원고가-보고한-결과와-한계"></a>

<a id="-원고가-보고한-결과와-한계"></a>

### 원고가 보고한 결과와 한계

기억력·집중력 훈련 게임 중 개인에게 맞는 후보를 찾는 것이 연구의 출발점입니다. 원고는 ADHD 환자와 정상 대조군의 특성·게임 반응을 사례로 수집하는 절차를 제안하지만, 실제 수집 표본이나 사례 데이터는 제공하지 않습니다.

CBR 기반 개인화를 통해 인지 능력 향상을 돕는 것을 목표로 합니다. 이 연구는 추천 구조의 설계 단계이며, 임상 참여자·대조군의 전후 평가와 통계 검정을 통한 치료 효과 검증은 후속 과제입니다.

### 최종 원고 · 사례로 찾는 디지털 놀이치료

청소년의 특성과 게임 반응을 사례로 보관하고, 비슷한 사례를 이용해 디지털 놀이치료 게임을 추천하는 설계 연구입니다.

| 구성 | 처리 내용 |
| --- | --- |
| 사례 구성 | 나이·성별 등 사용자 특성과 게임 유형·반응·성과를 한 사례로 연결합니다. |
| 사례 검색 | 새로운 사용자의 특성에 맞는 과거 사례를 찾아 추천 근거로 사용합니다. |
| 게임 후보 구성 | 게임 메타데이터와 이전 반응을 바탕으로 개인에게 맞는 콘텐츠를 선택하는 흐름을 설명합니다. |
| 추천 후 평가 | 게임 이용 이후 반응과 인지 성과를 관찰하고 다음 추천에 반영하는 설계를 제시합니다. |

| 입력·실행 조건 | 내용 |
| --- | --- |
| 자료 | 학술 대회 논문집의 3쪽 전체 원고 |
| 읽기 도구 | PDF 뷰어 |
| 사례 항목 | 연령·성별·게임 종류와 이용 반응 등 |
| 평가 범위 | 추천 구조와 평가 절차의 제안 |

이 자료의 결과는 추천 시스템의 설계와 처리 흐름입니다. 정량 성능 결과표나 참여자 수·대조군 비교·통계 검정으로 입증한 임상 효과는 원고에 제시되지 않습니다.

기억력·집중력 향상은 설계의 목표입니다.

실제 사용자 반응을 수집하고 추천 결과를 평가하려면 개인정보 보호와 연구 절차를 갖춘 별도의 실증이 필요합니다. 원고에 쓰인 목표를 이미측정된 치료 효과로 바꾸어 해석하지 않습니다.

| 제약 | 확인할 내용 |
| --- | --- |
| 추천을 바로 실행하고 싶을 때 | 유사도 수식·학습 데이터·실행 가능한 추천 서비스는 이 자료에 포함되지 않습니다. |
| 논문 연도를 확인할 때 | 원고의 학술 대회 표기는 2024년입니다.<br>컴퓨터의 보관 연도와 구분합니다. |
| 효과 수치를 인용할 때 | 이 원고는 설계 제안이며 치료 전후의 정량 실험 결과를 제공하지 않습니다. |
